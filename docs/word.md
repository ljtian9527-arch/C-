# 栾树

入秋，天气转凉。栾树在山上撒开。

我第一次看它，是在山上的初秋。那时它茂密的绿叶上刚刚出现橙红的颜色，远远看去，仿佛几支花朵盛开。

我偶然经过那几棵栾树，结果发现那鲜艳的竟是它的叶子。

我大受震撼，那时我浅薄的见识仅仅来自书籍和小小的家，故乡把我留在那座小城和几间学校楼

我外出求学，第一次有时间每天出来看看天空和绿茵，去完整的经历日头渐削，秋色愈深

我那时是这么想的，“别的树都是叶子一起变黄或红，一看到便认为秋来将落红。它偏不！偏要一枝枝的红，要这枯萎的叶在深绿的丛里长成晚秋的艳丽；偏要将死亡长成盛开，所以越接近枯死，便正是热烈的开着。让人动容，这般炽热的生命和不甘的热情，它是在死亡里开的花。”

当然
  直到后来，我好好了解了它，才知道那艳丽的不是枯叶，而竟然是它的果实！只是它的果皮扁，我误会成了叶子。
  说来可笑，笑我见识少又自以为是...但那感动还在，所以我从此对栾树有着一种特殊的情愫
